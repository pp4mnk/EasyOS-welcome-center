# EasyOS Welcome Center by pp4mnk

## What is EasyOS Welcome Center?

**EasyOS Welcome Center** is an all-in-one control panel designed to help both new and experienced EasyOS users.

It brings together the most useful tools, utilities and configuration scripts in a single, easy-to-use interface. Instead of searching through menus or remembering terminal commands, everything is available from one central location.

Current features include:

* 🚀 First Steps
* 🌐 Web Browsers
* 📄 LibreOffice Word-like configuration
* 🔤 Microsoft-compatible font installation
* ⚡ System Optimizer
* 📊 System Benchmark
* 🔍 EasyOS Doctor
* 💾 Backup & Restore
* 🔄 Snapshot Management
* 🔒 Security tools
* 🌍 Network & Internet utilities
* 🧹 Maintenance & Cleanup
* 🖥 System Information
* ⚙ System Configuration
* 📦 Package Management
* ❓ Help & Documentation

The project has been designed to become the central starting point for EasyOS, making the operating system easier to discover, configure and maintain.

---

# Installation

Open a terminal and run:

```bash
tar -xzf easyos-welcome-center-pp4mnk-v1.0-large-grid.tar.gz
cd easyos-welcome-center-v0.9
chmod +x install.sh
./install.sh
```

---

# Launching EasyOS Welcome Center

You can start it from a terminal by typing:

```bash
easyos-welcome-center
```

Or, even easier:

**Menu → System → EasyOS Welcome Center**
